# مترجم همزمان (فارسی ⇄ انگلیسی)

یک دکمه بزرگ قرمز: انگشت را نگه دارید و صحبت کنید، انگشت را بردارید تا ترجمه با صدای بلند پخش شود.

## ساخت فایل APK بدون نصب هیچ برنامه‌ای (با GitHub)
1. در github.com یک حساب رایگان بسازید و یک مخزن (Repository) جدید بسازید.
2. دکمه «Add file ← Upload files» را بزنید و **همه محتویات این پوشه** را (از جمله پوشه `.github`) آپلود کنید.
   نکته: پوشه‌هایی که با نقطه شروع می‌شوند ممکن است در ویندوز مخفی باشند؛ نمایش فایل‌های مخفی را روشن کنید.
3. به تب **Actions** بروید. ساخت خودکار شروع می‌شود (حدود ۵ دقیقه).
4. پس از سبز شدن، روی آن کلیک کنید و از بخش Artifacts فایل `TalkTranslate-APK` را دانلود کنید.
5. فایل zip را باز کنید، `app-debug.apk` را به گوشی بفرستید و نصب کنید
   (اجازه «نصب از منابع ناشناس» را بدهید).

## روش دوم: Android Studio
پوشه را در Android Studio باز کنید و دکمه Run را بزنید.

## اولین اجرا
- اجازه میکروفون را بدهید.
- بار اول به اینترنت نیاز است تا مدل‌های ترجمه (حدود ۶۰ مگابایت) دانلود شوند. بعد از آن ترجمه آفلاین است.
- تشخیص گفتار از سرویس گوگل گوشی استفاده می‌کند و معمولاً به اینترنت نیاز دارد.

## اگر صدای فارسی پخش نشد
در تنظیمات گوشی بخش «خروجی تبدیل متن به گفتار» (Text-to-speech) را باز کنید
و موتوری را انتخاب کنید که فارسی دارد (مثلاً Google Speech Services به‌روز، یا موتورهای فارسی موجود در بازار/گوگل‌پلی)
و داده صوتی فارسی را دانلود کنید.

## اگر تشخیص خودکار زبان خوب کار نکرد
روی نوشته بالای صفحه بزنید تا حالت را دستی روی «فارسی به انگلیسی» یا «انگلیسی به فارسی» بگذارید.
